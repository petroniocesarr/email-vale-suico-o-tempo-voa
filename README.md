# ✉️ Vale Suíço Resort — O Tempo Voa

Template de E-mail Marketing institucional e de conversão para o **Vale Suíço Resort**.

Você pode visualizar o layout responsivo diretamente no link do GitHub Pages:  
👉 **[Visualizar E-mail Marketing](https://petroniocesarr.github.io/email-vale-suico-o-tempo-voa/)**

## 🎯 Conceito & Mensagem
- **Conceito:** *O tempo voa; os momentos em família ficam.*
- **Sequência de Fases:**
  1. **Fase Bebê (Topo):** *“Hoje, no colo. Daqui a pouco, nas próprias aventuras.”*
  2. **Fase Criança (Meio):** *“Muito menos telas. Muito mais Vale Suíço.”*
  3. **Fase Beach Tênis:** *“Eles crescem. Os momentos ficam.”*
  4. **Fase Verão (Fechamento):** *“Verão chegando, deste tamanho!”*

## 🔘 Botões de Conversão (CTAs nas Fotos)
- Botões sobrepostos diretamente nas fotos com borda branca e sombra projetada:
  - `Reserve online 24h` *(Azul `#24418C`)*
  - `Reserve com o time do Vale` *(Verde WhatsApp `#259B40`)*
  - `Escolha aqui a sua próxima viagem!` *(Verde `#259B40` para a foto de Verão)*

- `index.html`: Código HTML responsivo do e-mail (compatível com Outlook, Gmail, Apple Mail e RD Station).

- `VALE-SUICO_EMAIL_O-TEMPO-VOA_DESKTOP.png`: Renderização completa Desktop.
- `VALE-SUICO_EMAIL_O-TEMPO-VOA_MOBILE.png`: Renderização completa Mobile.
- `VALE-SUICO_EMAIL_O-TEMPO-VOA.zip`: Arquivo zipado pronto para importação em plataformas de disparo.
